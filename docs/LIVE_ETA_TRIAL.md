# Private prospective ETA trial

The existing 20-second shadow worker now records two additional candidates in `live_eta_trial`, in the private shadow SQLite database. This does not modify public API/website forecasts or the student-source collector.

- `issued_stop_calibrated_v1`: stop/predicted-lead correction from a frozen report artifact (maximum age 12 hours). Train only on completed GPS-proxy events within the previous seven days. Fallback from stop/band to band or global, requiring 12 local or 25 broader unique events and three local days. The base speed variant must be available. The report is produced on the existing 30-minute timer.
- `downstream_time_of_day_v1`: estimate the next principal stop beyond the currently predicted stop in the same direction; skip optional 135th Street as a downstream target. Add historical arrival-to-arrival segment durations, with an hour-conditioned sample if sufficient history exists. This incorporates intermediate stop dwell without adding it twice; not a separate departure or dwell predictor. At least 12 segments and three local days, using only completed past segments within 14 days. No wraparound loop or standing/stale GPS forecast. Range is a heuristic sum of segment quantiles, not a calibrated confidence interval.
- Freeze the most recent matching student reference already ingested at issuance (age <=45s, future ETA <=45m). Preserve candidates with no reference as well. Never acquire additional data from the student tracker or Samsara for this trial. All source predictions are experimental.
- Store one row per model, vehicle, direction, stop and source fix, with actual recording timestamp. Do not backfill the trial. At evaluation, wait 45 minutes from issuance, use the first subsequent GPS-inferred stop passage only if direction agrees, it follows recording, and the GPS track has no >120s gap. Track pending, missing, ambiguous and gap-excluded records separately. Compare one first-issued candidate per model/event/issued lead band. Repeated bands for one event are correlated; counts are not independent arrivals. Source and our interval coverage are GPS-proxy coverage only. No release gate is changed.
- A private scorecard appears under `matchedComparison.liveTrial`; aggregate model profiles under `matchedComparison.liveCalibrationProfiles`. Private reports must remain mode 0600. Existing `NOT_APPROVED` policy remains. No independent Samsara access, live traffic, dedicated stationary departure estimation, or true observed boarding validation is added here.

Tests include no future training, expired profiles, downstream routing, already-ingested reference selection, deduplication, missing direction, GPS gaps, pending outcomes, and the synthetic end-to-end GPS-to-shadow path. Start with zero real trial forecasts; only future source fixes will populate it. Back up existing modules before restarting only the ETA shadow worker. Rollback restores previous modules; the private trial table may remain inert.
